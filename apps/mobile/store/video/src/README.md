# فيديو «جاوب أو بادل» الترويجي — المصدر

كل شي في الفيديو مولَّد من هذا المجلد: الحركة صفحة HTML، والصوت مركّب رقميًا بـ Python، والتصيير بـ Chrome و ffmpeg.
لا توجد موسيقى أو مؤثرات أو صور من خارج المستودع: اللقطات من `../../screenshots/raw/iphone-6.9/`، والأيقونة من
`apps/web/public/icons/app-icon-action.png`، والخط Tajawal من `node_modules/@fontsource/tajawal`.

## إعادة التوليد بأمر واحد

من جذر المستودع:

```bash
node apps/mobile/store/video/src/render.mjs --work /مسار/مجلد/مؤقت
```

الأمر يولّد الصوت، ويصيّر النسختين، ويرمّزهما، ويتحقق منهما، ويكتب الناتج في `apps/mobile/store/video/`:

- `jawabbadel-promo-1080x1920.mp4` — النسخة العامة (إطار جوال ثلاثي الأبعاد).
- `jawabbadel-app-preview-886x1920.mp4` — نسخة App Preview لآيفون 6.9" (لقطات التطبيق بملء الشاشة، 10–12 ميغابت، H.264 High 4.0).

المدة على Mac بمعالج M5 Max حوالي 3 دقائق للنسختين. الملفات المؤقتة (المقاطع بلا فقد، الصوت WAV، ملفات Chrome) تُكتب في `--work`
(الافتراضي مجلد مؤقت في النظام)، وتحتاج حوالي 3 GB.

خيارات مفيدة:

| الخيار | المعنى |
|---|---|
| `--only promo` أو `--only preview` | نسخة واحدة فقط |
| `--workers 8` | عدد نسخ Chrome المتوازية |
| `--sub 4` | عيّنات التمويه الحركي لكل إطار (1 = بدون تمويه، أسرع) |
| `--skip-audio` | استعمل الصوت الموجود في `--work` بدل توليده |
| `stills --mode preview --times 3,12.5 --out DIR` | لقطات PNG ثابتة للمراجعة |

## الأدوات اللازمة

- Node.js 22 أو أحدث (يستعمل WebSocket المدمج للتحكم بـ Chrome عبر DevTools Protocol، بدون Puppeteer).
- Google Chrome (المسار الافتراضي على macOS، أو متغير البيئة `CHROME`).
- ffmpeg و ffprobe (الافتراضي `/opt/homebrew/bin`، أو `FFMPEG` و `FFPROBE`).
- Python 3 بالمكتبة القياسية فقط (بدون numpy).
- `npm install` في جذر المستودع حتى يوجد خط Tajawal.

## الملفات

- `timeline.js` — الإيقاع (124 نبضة/دقيقة) وجدول الأحداث بالنبضات. تقرؤه الحركة والصوت معًا، فأي تعديل فيه يحرك الاثنين بنفس التزامن.
- `motion.js` و `style.css` و `index.html` — الحركة كلها دالة نقية `render(t)`؛ لا تعتمد على الساعة ولا على requestAnimationFrame.
  الوضع يُختار بالرابط: `index.html?mode=promo` أو `?mode=preview`، ويمكن إضافة `&t=12.5` لعرض لحظة معينة أو `&play=1` للتشغيل
  (افتح Chrome بخيار `--allow-file-access-from-files` حتى يحمّل الخط من الملفات المحلية).
- `audio.py` — الموسيقى (kick و clap و hat و snare وباص وكوردات ولحن) والمؤثرات (whoosh، pop، ding، انفجار، كونفيتي، عدّاد، نغمة فوز).
  `AUDIO_STATS=1` يطبع مستويات كل مسار.
- `render.mjs` — التصيير المتوازي والترميز والتحقق.

## ملاحظات لمتجر أبل

نسخة 886×1920 مصممة لقيود App Preview: أغلب المدة لقطات حقيقية من واجهة التطبيق بملء الشاشة والعناوين فوقها،
بدون ذكر منصات أخرى ولا أسعار ولا «مجاني» ولا «حمّل الآن». الإطار الافتراضي للملصق (poster frame) عند الثانية 5
يقع على الشاشة الرئيسية مع عنوان «أنشئ غرفة وادعُ أصحابك».
