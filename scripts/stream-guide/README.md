# فيديو شرح البث

الفيديو اللي يفتح من زر «🎬 شاهد الشرح» في صفحة البث (`apps/web/public/videos/stream-guide.mp4`).
يشرح البداية وطور «جاوب أو بادل»، بصوت آلي عربي وكتابة على الشاشة، ومتسجّل من الموقع الحقيقي في وضع التجربة.

لإعادة التسجيل بعد تغيير الواجهة أو الكلام:

1. عدّل الكلام في `narration.json` (عربي مشكّل كامل عشان ينقرأ صح)، وشغّل `python3 scripts/stream-guide/synth.py` (التفاصيل أول الملف).
2. شغّل السيرفر محليًا على 3999 (مع قاعدة بيانات فيها فئات جغرافيا وكرة قدم وتاريخ، ومنها سؤال «ما هي عاصمة الإمارات؟» بـ200 نقطة).
3. `node scripts/stream-guide/record.cjs` (يحتاج Playwright) — كل خطوة تطول بقدر جملتها.
4. `python3 scripts/stream-guide/assemble.py` — يقص المشاهد ويركّب الصوت ويكتب الفيديو والصورة في `apps/web/public/videos/`.
