# بنك الأسئلة — تعليمات توليد الأسئلة (كوديكس)

أي ملف JSON في هذا المجلد يدخل لوحة التحكم **كسؤال مقترح**، ولا يظهر في اللعبة إلا إذا اعتمده المشرف من صفحة «بنك الأسئلة».

## صيغة الملف

اسم الملف: `<الفئة>-<رقم>.json` مثل `geo-001.json`. الملف قائمة أسئلة:

```json
[
  {
    "categorySlug": "geo",
    "points": 100,
    "text": "ما هي عاصمة أستراليا؟",
    "options": ["سيدني", "ملبورن", "كانبيرا", "بريسبان"],
    "correctIndex": 2,
    "reference": "https://ar.wikipedia.org/wiki/كانبرا"
  }
]
```

| الحقل | الوصف |
|---|---|
| `categorySlug` | معرّف الفئة من الجدول تحت |
| `points` | الصعوبة: `100` سهل جدًا … `500` صعب جدًا |
| `text` | نص السؤال بالعربي الفصيح البسيط، حتى 500 حرف |
| `options` | 4 خيارات مختلفة، كل خيار حتى 120 حرف |
| `correctIndex` | رقم الخيار الصحيح من `0` إلى `3` |
| `reference` | **مطلوب**: رابط أو ملاحظة قصيرة يتأكد منها المراجع من الإجابة |

`type` يكون `text` تلقائيًا. لا تكتب أسئلة صور: هذي يضيفها المشرف يدويًا مع صورة حقيقية.

## الفئات

| المعرّف | الفئة |
|---|---|
| `history` | تاريخ |
| `geo` | جغرافيا |
| `football` | كرة قدم |
| `cars` | سيارات |
| `flags` | أعلام دول |
| `career` | مسيرة لاعب: «لعب في نادي (سنة) ثم نادي (سنة) … — من هو اللاعب؟» |

## القواعد

- **إجابة واحدة صحيحة بلا جدال.** تجنّب «الأسرع/الأكبر/الأحدث» إذا كانت تتغير مع الوقت أو عليها خلاف، أو اذكر السنة في السؤال.
- الخيارات الخاطئة معقولة ومن نفس النوع (أربع مدن، أربعة لاعبين…)، وطولها قريب من الصحيحة.
- لا تجعل الإجابة الصحيحة في نفس المكان دائمًا (اللعبة تخلط الخيارات، لكن التنوع يسهّل المراجعة).
- وزّع الأسئلة على النقاط الخمس بالتساوي تقريبًا. الفئة ما تظهر في اللعبة إلا إذا فيها سؤال معتمد لكل مستوى.
- لا تكرر سؤالًا موجودًا. المكرر يُتجاهل تلقائيًا عند التحميل، لكنه جهد ضائع.

## التحميل

```bash
npm run bank:load -w @quiz/server            # كل ملفات المجلد
npm run bank:load -w @quiz/server -- bank/geo-001.json
```

إعادة التحميل آمنة: السؤال اللي نصه موجود في نفس الفئة (مقترح أو معتمد أو مرفوض) ما ينضاف مرة ثانية. الملف اللي فيه خطأ ما ينحمل منه شيء، والرسالة تذكر رقم السطر.

بديل بدون سطر أوامر: صفحة «بنك الأسئلة» في لوحة التحكم ← «رفع ملف مقترحات».
